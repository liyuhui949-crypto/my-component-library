# Vxe Grid Data组件

## 开发依赖

> 使用`titleSuffix`(口径说明), 官网文档说是需要 `vxe-table@4.5.21`版本, 实际上当前的配置就能使用, 而且也没有看到有这么高的版本

```json
{
    "vxe-pc-ui": "4.12.36",
    "vxe-table": "4.17.48",
}
```

## 功能

`Index.vue`: `vxe-grid`配置式表格, 纯 JSON 生成表单. 所以只需要接收一个配置项即可
- 接收列配置项, 包含 data数据, loading等状态值
- 初始化并更新分页参数, 调用 search 方法
- 向父组件暴露分页参数(不带total)

## 配置项

配置项中可以做到很多事情, 比如分组表头、口径说明、右侧按钮组等
